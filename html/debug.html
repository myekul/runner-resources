This is the Cuphead Debug Mod, the premier tool for practice and experimentation amongst top runners. It has many helpful features, such as health bars, hitboxes, level selection, and RNG control.

The debug mod is a patch that gets injected into the game at runtime through a Unity modding framework called BepInEx. Simply put, you're not downloading a modded version of the game, or modifying the game files directly—BepInEx basically launches the game and adds modifications upon launch.

To start using it, download the .zip and extract it in the same directory as Cuphead.exe. Launch Cuphead normally through Steam, and presto! If it skips the MDHR intro animation, it's working. If you want to turn off the debug mod, simply rename the BepInEx folder to something else and relaunch the game.
